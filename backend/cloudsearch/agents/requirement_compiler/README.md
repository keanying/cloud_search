# requirement_compiler 需求编译

**职责**：理解用户消息，决定是直接答复（chat）、澄清（clarify）还是创建联网任务（task），并输出 TaskSpec 候选与简版计划。

- 输入：用户最新消息、最近对话、用户选择的模式、待确认的旧计划（如有）
- 输出：`IntentDecision`（见 schemas.py）
- 工具：无（不能联网、浏览、写库）
- 确定性预检 `normalize_decision`：强制使用用户显式选择的模式；缺字段的数据任务转澄清；数据/混合任务首次必须确认字段；补齐默认输出格式
- 边界：“智能模式”只是选择策略，不是第五种任务模式；普通对话不建任务
