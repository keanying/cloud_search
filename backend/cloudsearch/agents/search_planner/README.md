# search_planner 搜索规划

**职责**：理解用户真实意图，生成并优化搜索词；从结果中挑出值得阅读的网页（由云端浏览器打开搜索引擎执行，不使用搜索API）。

1. **规划 plan_queries**：先写出意图（目的、对象、地区/时效/权威来源等隐含约束），再生成查询矩阵。
   查询可使用 `site:`、英文双引号精确匹配、年份；需要时设置 recency（DuckDuckGo 会按时间过滤）和 language（zh/en，影响地区）。
   程序补充：用户点名的对象、用户指定的站点必须被覆盖；去重（忽略大小写、引号、词序）并截断到上限。
2. **筛选 select_candidates**：按意图与来源权威性从候选中挑选要读的页面并排序；编号由程序校验，模型不能编造候选。
3. **改写 refine_queries**：无结果或结果无关的查询，参考实际返回的标题改写一次（同义词/规范名称/放宽条件/换语言）。

- 工具：无
- 边界：搜索结果标题/摘要只是发现线索，不能直接成为字段值或引用证据
