## 产品一句话

用户用一句话提出问题、调研或采集需求；云端的 8 个智能体分工协作（需求编译 → 搜索规划 → 浏览研究 → 信息抽取 → 核验 → 分析 → 报告写作，协调全程把关），
在**真实的云端浏览器**里搜索和阅读网页，交付**带引用来源、可直接使用**的回答、报告（Word/PDF/HTML/Markdown）和数据表（Excel/CSV）。
用户可以在右侧实时看到云端浏览器画面；遇到人机验证时任务暂停，由用户在实时画面里接手完成，系统不会尝试绕过验证。

## 信息架构

```
用户端（顶部深色浮动导航：对话 · 我的成果 · 设置 · 管理后台[管理员]）
├── /                 首页：搜索为主，向下滚动是产品介绍与亮点
├── /login            登录 / 注册
├── /chat/:id         对话工作台：左 对话列表 | 中 对话 | 右 本次任务 / 云端浏览器 / 来源 / 文件预览
├── /artifacts        我的成果：报告与数据文件（同一成果多格式合并）
└── /settings         设置：账号、偏好、外观

管理端（左侧深色导航，独立布局）
├── /admin/overview   概览
├── 模型：/admin/providers 供应方 · /admin/models 模型 · /admin/agents 智能体分工
├── 运行：/admin/search 搜索与浏览器 · /admin/limits 任务限额
└── 数据：/admin/tasks 任务 · /admin/runs 调用记录 · /admin/users 用户
```

## 设计关键词

人感、温暖、克制；像一个认真做事的研究助理，而不是炫技的 AI 产品。
暖白画布 + 黑色墨水按钮 + 薄荷/淡紫/奶黄/天蓝/蜜桃粉彩卡片；不用渐变、毛玻璃、发光、紫色科技风。
参考：Dei 类仪表盘（粉彩卡片、圆角、黑色胶囊按钮）、aside.com（首页搜索 + 向下滚动介绍）、ZenBrowser 新标签页、
Google 涂鸦/Chrome 主题插画、Semi Design 表格、Analytics 深色侧栏后台。
