# 设计系统

## 1. 设计原则

1. **人感优先**：语气像同事，不像机器。文案用短句、口语；状态用“正在打开网页实读（5/12）”而不是“Executing step 3”。
2. **结果可直接用**：每个回答都带来源编号、可悬停查看原文；报告、表格一键下载，图表已经组装好。
3. **过程透明但不打扰**：进度、浏览器画面放在右侧，对话区只保留关键卡片；需要人时（人机验证）才醒目提示。
4. **磨砂玻璃 + 靛紫**：半透明白色玻璃面板浮在浅灰网格背景上，背景有淡淡的紫、青、粉光斑；主操作与选中统一用靛紫渐变并带柔和光晕；幻彩渐变只用于成果卡片、Logo、头像等少数点缀；状态色只用于小圆点和胶囊。
5. **宽屏友好**：内容最大宽度 1680px；宽屏三栏，窄屏抽屉；不出现“窄窄一列”在大屏中间。

## 2. 色彩

全部定义在 `web/src/style.css` 的 `:root` / `html.dark` 中，组件只引用变量。

| 角色 | 变量 | 值 | 用途 |

| 玻璃面板 | `--cs-surface` | `rgba(255,255,255,.60)` + `backdrop-filter: blur(22px) saturate(1.7)` | 卡片、侧栏、顶栏、面板 |

### 粉彩卡片（两色渐变底 / 强调文字 / 圆点）

粉彩卡片 `card-*` 是两种相近粉彩的 135° 渐变（带一点镭射感），外加 1px 白色高光描边。

| 名称 | 渐变 | 文字 | 圆点 | 语义（默认分配） |
|---|---|---|---|---|
| mint 薄荷 | `#DCF5EA → #DCEBFF` | `#134D36` | `#22B07D` | 进度、完成、数据成果、官方来源 |
| lilac 淡紫 | `#E7E2FF → #F5DEF6` | `#3A2F86` | `#6D5CF6` | 执行计划、报告、学术来源 |
| butter 奶黄 | `#FCF1C8 → #FFE2D4` | `#5A4808` | `#E0A400` | 需要你协助（人工接手）、提示、百科来源 |
| sky 天蓝 | `#DCE9FF → #E7DEFE` | `#1C3B6B` | `#3B82F6` | 文件已生成、权威媒体 |
| peach 蜜桃 | `#FFE2D8 → #F8DDF3` | `#702A14` | `#F0603A` | 出错、失败、聚合/转载来源 |

### 图表

靛紫为主色，其余依次为天青、玫红、薄荷、琥珀、淡紫（`lib/charts.ts`）。柱子顶部圆角、柱体竖向渐变；趋势线 2.5px 平滑曲线，白心圆点 + 渐隐面积；网格线虚线、极淡。

### 深色主题

画布 `#0D0E18`（带同样的网格与更明显的紫色光斑），玻璃面板 `rgba(30,32,52,.55)`，描边 `rgba(255,255,255,.09)`；主色提亮为 `#7477FF`；粉彩卡片改为低饱和深色两色渐变 + 浅色文字（如 mint `#17332A → #182A42`、字 `#BFEED6`）；头像始终使用浅色幻彩底。

## 3. 字体

- 字体栈：`Plus Jakarta Sans`（本地打包）, `PingFang SC`, `HarmonyOS Sans SC`, `Microsoft YaHei`, `Noto Sans CJK SC`, sans-serif。
- 字号：页面标题 32–36/700；卡片标题 15–17/700；正文 16/1.75（回答正文）、14（界面）；说明 12–13；数字统计 26–40/700，`tabular-nums`。
- 代码/参数键：等宽 12px，灰色（如 `requirement_compiler`）。

## 4. 形状、阴影、间距

- 圆角：卡片 24px（`rounded-3xl`）；内层块/输入框 16px；按钮、胶囊、标签、侧栏导航项全圆角（999px）；后台面板 22px；抽屉、弹窗 22–26px。
- 阴影（`--cs-shadow`）：顶部 1px 内高光 `inset 0 1px 0 rgba(255,255,255,.7)` + `0 14px 34px -20px rgba(40,44,90,.30)`；浮层（`--cs-shadow-lg`）`0 30px 60px -26px rgba(40,44,90,.38)`。
- 玻璃：`backdrop-filter: blur(22px) saturate(1.7)`（`--cs-blur`），所有面板、顶栏、侧栏、弹出层统一使用。
- 间距：8 的倍数；卡片内边距 20–24px；栅格间距 16–20px。
- 动效：150ms 悬停上浮 1–2px；进度圆点轻微脉冲；尊重 `prefers-reduced-motion`。

## 5. 组件规范

| 组件 | 规格 |
|---|---|
| 主按钮 `btn-primary` | 靛紫渐变胶囊 + 光晕，白字 14px/600，高 36；小号 30 |
| 次按钮 `btn-secondary` | 白色玻璃胶囊 + 白色高光描边；`btn-ghost` 无底 |
| 圆形按钮 `round-btn` | 40×40 靛紫渐变圆 + 光晕，发送箭头 |
| 输入框 | 半透明白底、16px 圆角（搜索框全圆角）、1px 描边，聚焦靛紫描边 + 4px 淡紫光圈 |
| 胶囊 `pill` | 12px/600，状态胶囊前带 6px 圆点（可用=绿、需验证=紫、无法访问=橙红、冷却中=黄） |
| 筛选 `chip` | 白色玻璃胶囊，选中为靛紫渐变 + 光晕（`chip-active`） |
| 分段控件 | 玻璃槽 + 靛紫选中块（7天/14天/30天、优先/轮换） |
| 开关 | 靛紫轨道 + 白色圆钮 |
| 统计块 `tile` | 粉彩渐变卡片内的半透明白块，左上数字 26–40px 粗体，下方 12px 标签 |
| 卡片 `surface` / `glass` | 磨砂玻璃 24px 圆角 + 白色高光描边 + 柔和投影 |
| 成果卡片 | 幻彩渐变底（`holo-card`），左上斜向白色光泽 |
| 顶栏 / 后台侧栏 | 悬浮玻璃条（距边 12px），当前项为靛紫渐变胶囊 |
| 引用编号 `cite-chip` | 16px 圆形，淡紫底靛紫数字，上标位置；悬停出预览卡 |
| 表格 `DataTable` | Semi 风格：浅灰表头 12px 粗体、行高 52（紧凑 40）、行悬停浅灰、列排序箭头、固定列阴影、分页（10/20/50）、骨架加载、空状态插画 |
| 抽屉 `SideDrawer` | 右侧滑出 480–560px，顶部标题 + 关闭，底部固定“取消/保存” |
| 吐司 | 右上角玻璃卡片，成功带绿色图标与描边、错误带红色图标与描边 |
| 空状态 | 线条小插画 + 一句话 + 一个主操作 |

图标：lucide 线性图标（1.75px 描边，16–20px），与 layui-vue 图标同类风格；不混用填充图标。

## 6. 响应式

| 宽度 | 用户端对话页 | 管理端 |
|---|---|---|
| ≥1440 | 三栏：左 280 对话列表 · 中 自适应 · 右 380–440 本次任务/浏览器 | 侧栏 248 + 内容最宽 1680 |
| 1280–1439 | 三栏，左 244 / 右 340 | 同上 |
| 1024–1279 | 左栏、右栏变抽屉，中间铺满 | 侧栏可收起为图标（72） |
| <1024 | 单栏；顶部按钮打开“对话列表”“本次任务”抽屉 | 侧栏变抽屉 + 顶部条 |
| 390 手机 | 输入框吸底，模式按钮折叠为下拉 | 表格横向滚动，关键列固定 |

## 7. 文案语气

- 称呼用户为“你”；不用“亲”“小助手”。
- 状态：理解需求并规划搜索 / 多引擎搜索 / 打开网页实读 / 抽取证据 / 核验引用 / 撰写报告。
- 人工接手：“需要你协助：Google 要求人机验证，请完成验证后点‘完成’”。
- 不夸大：“机器核验，未经人工审核”。
