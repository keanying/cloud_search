# 设计系统

## 1. 设计原则

1. **人感优先**：语气像同事，不像机器。文案用短句、口语；状态用“正在打开网页实读（5/12）”而不是“Executing step 3”。
2. **结果可直接用**：每个回答都带来源编号、可悬停查看原文；报告、表格一键下载，图表已经组装好。
3. **过程透明但不打扰**：进度、浏览器画面放在右侧，对话区只保留关键卡片；需要人时（人机验证）才醒目提示。
4. **克制的色彩**：大面积暖白 + 黑色墨水；粉彩只用于卡片底色区分信息类型；状态色只用于小圆点和胶囊。
5. **宽屏友好**：内容最大宽度 1680px；宽屏三栏，窄屏抽屉；不出现“窄窄一列”在大屏中间。

## 2. 色彩

### 浅色（默认）

| 角色 | 变量 | 值 | 用途 |
|---|---|---|---|
| 画布 | `--cs-bg` | `#F3F3EF` | 页面背景（暖白） |
| 表面 | `--cs-surface` | `#FFFFFF` | 卡片、输入框、表格 |
| 下沉表面 | `--cs-surface-sunken` | `#F7F7F3` | 卡片内的分组块 |
| 分隔线 | `--cs-line` / `--cs-line-strong` | `rgba(17,18,20,.08)` / `.14` | 1px 描边 |
| 墨水 | `--cs-ink` | `#111214` | 主按钮、用户气泡、顶栏、后台侧栏 |
| 墨水上的文字 | `--cs-on-ink` | `#FFFFFF` | |
| 强调绿 | brand-300/400 | `#157A52` / `#1F9163` | 链接、选中、引用编号、成功 |
| 正文 | slate-100 | 近黑 | 正文文字 |
| 次要文字 | slate-400/500 | `#9A9A94` / `#73736E` | 说明、时间 |

### 粉彩卡片（底色 / 强调文字 / 圆点）

| 名称 | 底色 | 文字 | 圆点 | 语义（默认分配） |
|---|---|---|---|---|
| mint 薄荷 | `#D5EEDF` | `#1D4D36` | `#2BB27A` | 进度、完成、数据成果、官方来源 |
| lilac 淡紫 | `#E3DEFA` | `#3B2F74` | `#7B68D8` | 执行计划、报告、学术来源 |
| butter 奶黄 | `#F6E9AD` | `#5A4808` | `#E0A400` | 需要你协助（人工接手）、提示、百科来源 |
| sky 天蓝 | `#D6E8F7` | `#1D3F61` | `#3D8BD4` | 文件已生成、权威媒体 |
| peach 蜜桃 | `#F9DACB` | `#6B2D14` | `#E46A3A` | 出错、失败、聚合/转载来源 |

后台概览的主卡片可用饱和橙 `#E8693C`（白字），只用一处。

### 深色主题

画布 `#161618`，表面 `#1F1F22`/`#28282C`，墨水反转为近白按钮（`--cs-ink` 浅色、文字深色），粉彩卡片改为低饱和深色底 + 浅色文字（如 mint 底 `#1E3329`、字 `#BFE6CF`）。顶栏与后台侧栏保持近黑。

## 3. 字体

- 字体栈：`Plus Jakarta Sans`（本地打包）, `PingFang SC`, `HarmonyOS Sans SC`, `Microsoft YaHei`, `Noto Sans CJK SC`, sans-serif。
- 字号：页面标题 32–36/700；卡片标题 15–17/700；正文 16/1.75（回答正文）、14（界面）；说明 12–13；数字统计 26–40/700，`tabular-nums`。
- 代码/参数键：等宽 12px，灰色（如 `requirement_compiler`）。

## 4. 形状、阴影、间距

- 圆角：卡片 24px（`rounded-3xl`）；内层块/输入框 16px；按钮、胶囊、标签全圆角（999px）；表格容器 20px。
- 阴影：`0 1px 2px rgba(17,18,20,.04), 0 6px 18px -10px rgba(17,18,20,.10)`；浮层 `0 24px 48px -22px rgba(17,18,20,.22)`。
- 间距：8 的倍数；卡片内边距 20–24px；栅格间距 16–20px。
- 动效：150ms 悬停上浮 1–2px；进度圆点轻微脉冲；尊重 `prefers-reduced-motion`。

## 5. 组件规范

| 组件 | 规格 |
|---|---|
| 主按钮 `btn-primary` | 黑底白字胶囊，14px/600，高 36；小号 30 |
| 次按钮 `btn-secondary` | 白底 + 1px 描边；`btn-ghost` 无底 |
| 圆形按钮 `round-btn` | 40×40 黑色圆，发送箭头 |
| 输入框 | 白底、16px 圆角、1px 描边，聚焦绿色描边 + 2px 淡绿光圈 |
| 胶囊 `pill` | 12px/600，状态胶囊前带 6px 圆点（可用=绿、需验证=紫、无法访问=橙红、冷却中=黄） |
| 筛选 `chip` | 白底描边胶囊，选中为黑底白字 |
| 分段控件 | 浅灰槽 + 黑色选中块（7天/14天/30天、优先/轮换） |
| 开关 | 黑色轨道 + 白色圆钮 |
| 统计块 `tile` | 粉彩底，左上数字 26–40px 粗体，下方 12px 标签 |
| 卡片 `surface` | 白底 24px 圆角 + 细描边 + 轻阴影 |
| 引用编号 `cite-chip` | 16px 圆形，淡绿底绿色数字，上标位置；悬停出预览卡 |
| 表格 `DataTable` | Semi 风格：浅灰表头 12px 粗体、行高 52（紧凑 40）、行悬停浅灰、列排序箭头、固定列阴影、分页（10/20/50）、骨架加载、空状态插画 |
| 抽屉 `SideDrawer` | 右侧滑出 480–560px，顶部标题 + 关闭，底部固定“取消/保存” |
| 吐司 | 右上角黑色胶囊，成功带绿点、错误带橙点 |
| 空状态 | 线条小插画 + 一句话 + 一个主操作 |

图标：lucide 线性图标（1.75px 描边，16–20px），与 layui-vue 图标同类风格；不混用填充图标。

## 6. 响应式

| 宽度 | 用户端对话页 | 管理端 |
|---|---|---|
| ≥1440 | 三栏：左 280 对话列表 · 中 自适应 · 右 380–440 本次任务/浏览器 | 侧栏 248 + 内容最宽 1680 |
| 1280–1439 | 三栏，左 244 / 右 340 | 同上 |
| 1024–1279 | 左栏、右栏变抽屉，中间铺满 | 侧栏可收起为图标（72） |
| <1024 | 单栏；顶部按钮打开“对话列表”“本次任务”抽屉 | 侧栏变抽屉 + 顶部条 |
| 390 手机 | 输入框吸底，模式按钮折叠为下拉 | 表格横向滚动，关键列固定 |

## 7. 文案语气

- 称呼用户为“你”；不用“亲”“小助手”。
- 状态：理解需求并规划搜索 / 多引擎搜索 / 打开网页实读 / 抽取证据 / 核验引用 / 撰写报告。
- 人工接手：“需要你协助：Google 要求人机验证，请完成验证后点‘完成’”。
- 不夸大：“机器核验，未经人工审核”。
