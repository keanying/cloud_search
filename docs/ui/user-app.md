## 3. 对话工作台 `/chat/:id`（核心页面）

**三栏布局（≥1280）**

### 左栏：对话列表（280）
- 顶部黑色胶囊「＋ 新对话」+ 收起按钮；搜索框“搜索对话”。
- 分组：今天 / 最近 7 天 / 更早。每项：标题（单行省略）+ 次行“2 分钟前 · 执行中”；左侧状态圆点（执行中=绿色脉冲，已完成=灰空心）。当前项白底卡片。

### 中栏：对话
- 顶部：会话标题（20/700）+ 右侧「本次任务」按钮（窄屏）。
- 用户消息：右对齐黑色气泡（圆角 26，右下 8），白字；下方可选模式标签（如“深入研究”）。
- 助手消息（左侧 36px Logo 头像），按顺序由以下卡片组成：
  1. **执行计划卡**（lilac）：标题“执行计划 · 数据+报告 · 已确认”，任务名，范围说明，5 步编号清单（白色内嵌块），底部胶囊“最多 6 次搜索 · 最多读取 12 个来源”，可展开“字段（12）”。需要确认时底部有「开始执行」「调整范围」。
  2. **进度卡**（mint）：左侧阶段时间线（勾选圆=完成、绿环=进行中、虚线圆=未开始：规划搜索、浏览器搜索、读取网页、提取信息、评估覆盖/补查、核验来源、整理数据、计算分析、撰写报告），右侧 2×3 白色统计块（搜索 9、候选 42、已读来源 8、读取受限/失败 4、证据 214）；底部「查看浏览器」「来源」。
  3. **需要你协助卡**（butter，轻微倾斜 -1°）：“需要你协助 · Google 要求人机验证，请完成验证后点‘完成’”，右上倒计时 4:43，黑色按钮「打开浏览器」。
  4. **关键数字**：一行 2–4 个粉彩数字卡（如“182 亿美元 · 智能体赛道融资 [1]”），点击打开来源。
  5. **回答正文**（白色卡片）：Markdown 排版（H2 带左侧色条、要点列表、表格、引用编号上标）；内嵌图表（柱状/折线，粉彩配色，下方“数据来源：…”）；奶黄色提示块（局限说明）。底部工具条：复制 · Word · PDF · HTML · Markdown 下载，右侧「查看完整报告」。
  6. **引用悬停预览**：悬停引用编号出现 360px 浮层：编号 + 站点 + 可信度标签（官方/学术/权威媒体/百科/社区/聚合/一般网站，用对应粉彩）+ 发布日期；标题；左侧竖线引用的原文摘录（5 行内）；「查看来源详情」「打开原网页 ↗」。
  7. **文件已生成卡**（sky）：文件图标、“报告已生成 · AI创业方向研究报告 · 机器检查”，右侧黑色「预览」，下方格式胶囊（Word/PDF/HTML/Markdown，各带彩色圆点和下载图标）。

  9. **接着问**：标签“接着问”，3 个白色描边胶囊问题（↳ 图标），点击直接发送。
- 澄清卡：白卡片 + 可点击的问题胶囊；错误卡：peach。

## 4. 上传文件与文件问答

用户可以把文件交给云搜：总结、问答、提取表格、写分析报告，或结合网上资料核对。文件解析成 Markdown 后作为**可引用的来源**，回答里的编号能定位到具体文件和部分（长文档按章节/页码拆分）。

**支持的格式**：PDF、Word（doc/docx）、Excel（xls/xlsx）、CSV/TSV、PPT（ppt/pptx）、图片（png/jpg/webp/bmp/gif/tiff）、TXT/Markdown/JSON/HTML、RTF/ODT/EPUB/OFD 等；单个 ≤100MB，一条消息 ≤10 个。
扫描件、图片、PPT 需要管理员配置 MinerU（自部署或 mineru.net 云端），否则解析失败并提示配置方法；表格与文本类文件总是内置解析。

### 4.1 添加附件
- 入口：输入框左下角回形针按钮（首页搜索条右侧也有）；把文件拖到对话区任意位置；在输入框里粘贴文件或截图（截图自动命名“截图-时间.png”）。
- 拖入时整列出现薄荷色虚线遮罩：“松开即可上传 · PDF、Word、Excel、PPT、图片、TXT / Markdown… 单个不超过 100MB”。拖到对话区外不会让浏览器打开文件。
- 选中后**立即上传**（首页会先建好对话）；客户端先校验类型、大小、数量，不合格用吐司说明原因。

### 4.2 附件卡片（输入框上方，宽 264）
左侧按类型着色的图标块（PDF 蜜桃、Word 天蓝、Excel/CSV 薄荷、PPT 奶黄、图片淡紫、文本灰），文件名中间省略，第二行状态：

| 状态 | 显示 |
|---|---|
| 上传中 | “上传中 37% · 8.6 MB”，底部 3px 绿色进度条 |
| 排队解析 / 解析中 | 转圈 + “排队解析” / “解析中…” + 大小 |
| 已解析 | 绿色“已解析 · 48 页 · MinerU”（或“内置解析”） |
| 解析失败 | 橙红描边，“解析失败”，悬停看原因；右侧「重试」（重新解析） |
| 上传失败 | 橙红“上传失败原因” |

右上角 × 移除（已上传的会删除服务器上的文件）。点卡片打开右侧文件预览。
- 上传中不能发送；解析中可以发送（回答会等解析完成再开始）。
- 只有附件、没有文字时占位符变为“问问这些文件…（直接发送即总结）”，发送后用户消息为“请阅读并总结我上传的文件”。

### 4.3 消息里的文件
用户气泡下方右对齐的文件卡片（白底，单个宽 260，多个两列），图标 + 名称 + “已解析 · 12 页 · MinerU · 4.6 MB”，状态随解析实时更新；点击预览。

### 4.4 文件预览（右侧面板“文件”标签）
- 头部：类型图标、文件名、解析方式徽标（如“MinerU（自部署） · standard”/“内置解析”）、页数 / 表格数 / 图片数 / 字数 / 大小，「原文件」下载。
- 已解析：可折叠的“大纲”（按标题层级缩进，点击滚动到对应标题），下面是渲染后的 Markdown（表格用正文表格样式，图片位置显示“〔图片：说明〕”）。超过 30 万字只预览前 30 万字，回答仍读取全文。
- 解析中：转圈 + “正在解析…大文件、扫描件用 MinerU 识别可能需要几分钟；现在就可以提问”。
- 解析失败：蜜桃色卡片“没能读取这个文件” + 原因 + 处理建议（需要 MinerU 时说明配置项），「重新解析」按钮。

### 4.5 回答与来源
- 任务进度增加第一阶段“读取文件”；只问文件内容时不联网，阶段为 读取文件 → 提取信息 → 核验来源 → 撰写成果；需要核对网上资料时文件阶段之后照常搜索。
- 文件来源：文件图标 + 标题（如“年报.pdf · 第 1–18 页”）+ 薄荷色徽标“你上传的文件”，不显示网址；点击打开文件预览。
- 引用悬停预览中，文件来源显示“查看文件”（代替“打开原网页”）；点击引用编号直接打开文件预览。
- 来源卡片标题行增加“你上传的文件 N 处”。

### 4.6 本次任务看板
新增“对话中的文件”卡片：列出本对话已发送的文件及实时解析状态，点击预览。没有任务时也显示。

## 5. 我的成果 `/artifacts`

- 页头：「← 返回」、标题“我的成果”、说明“同一份成果的 Word / PDF / Excel 等格式合并显示”；右侧 3 个统计块：报告 4（lilac）、数据 3（mint）、全部成果 7（butter）。
- 工具条：搜索框“搜索成果名称”、筛选胶囊（全部 / 报告 / 数据 / 其他文件）、右侧网格/表格切换。
- 网格：自适应列（最小 280px），卡片按类型着色（报告 lilac、数据 mint）：顶部类型标签 + 记录数标签、右上“回到对话”图标按钮；标题两行；“7 小时前 · 4 种格式 · 767.4 KB · 机器检查”；格式下载胶囊；右下黑色「预览」。
- 表格视图：名称、类型、格式、大小、记录数、生成时间、操作。
