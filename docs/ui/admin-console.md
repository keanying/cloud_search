# 管理端（控制台 v2）

> v1 沿用了用户端的视觉（36px 带图标标题、悬浮圆角侧栏、大面积粉彩卡片），读起来像宣传页而不是工作台；
> 保存方式不统一（逐行保存 + 保存全部、浮动保存条、抽屉）；模型配置拆成三页；表格点了没有下文。
> v2 改为**克制、紧凑、专业的控制台**：保留产品的暖白底色、墨色与绿色强调，粉彩只用于小面积状态与标签。

## 1. 布局

```
┌──────────┬───────────────────────────────────────────────────────────────┐
│ 侧栏 232 │ 顶部工具栏 56：面包屑 · ⌘K 命令面板 · 主题 · 用户菜单          │
│ #111214  ├───────────────────────────────────────────────────────────────┤
│ 贴边全高 │ 页头：标题 22/700 + 说明 13 + 右侧操作                         │
│          │ （可选标签行）                                                 │
│ 分组导航 │ 内容（最大宽 1600，左右 32 内边距）                             │
│          │                                                               │
│ 返回应用 │                              [ 底部保存条（有修改时出现） ]     │
│ 收起导航 │                                                               │
└──────────┴───────────────────────────────────────────────────────────────┘
```

- **侧栏**：贴边、全高、无外边距与圆角；当前项为浅白底 + 左侧 2px 绿色指示线；可收起为 64px 图标栏（记住选择）；<1024px 变为抽屉，由顶部「≡」打开。
- **顶部工具栏**：吸顶、半透明画布底 + 细分隔线；左侧面包屑（管理后台 / 分组 / 页面）；右侧命令面板入口（「搜索页面、任务、用户… Ctrl K」）、深浅色切换、用户菜单（姓名、@用户名 · 管理员、返回应用、退出登录）。
- **命令面板**（⌘K / Ctrl+K）：输入即过滤后台页面（含关键词，如“密钥”“验证码”“上限”），并搜索任务与用户；↑↓ 选择，Enter 打开（任务/用户直接打开详情抽屉）。

## 2. 视觉与排版

| 项 | 规格 |
|---|---|
| 字号 | 基准 14；表格 13；表头与分组名 12（灰）；页面标题 22/700；面板标题 14/600；KPI 数字 28/700 |
| 面板 `ac-panel` | 白底、1px 细描边、12px 圆角、无阴影；面板头 48 高，标题 + 灰色副说明 + 右侧链接 |
| 控件 | 按钮、输入框、下拉 8px 圆角，高 32（小号 28）；状态胶囊保留全圆角 |
| 颜色 | 粉彩只用于：状态胶囊、KPI 小图标方块、头像底色；不再用粉彩做大卡片底 |
| 表格 | Semi 风格：浅灰表头 12px、行高约 48（紧凑 36）、行悬停、当前查看的行浅绿高亮、固定列阴影、分页 10/20/50 |
| 抽屉 | 右侧滑出，16px 左侧圆角；头部可放标题区与操作（如「打开对话」），下方可有标签页 |
| 图标 | lucide 线性 16px，与 layui 图标同类风格 |
| 暗色 | 画布 #161618、面板 #1F1F22，侧栏 #0F0F11 + 右侧细线 |

样式层实现：`web/src/styles/admin.css`，只在 `<html class="admin-mode">`（进入后台时添加）下生效，不影响用户端。

## 3. 交互规则（全后台统一）

1. **编辑**：所有可编辑页面一律“行内编辑 → 底部保存条统一保存”。保存条：「N 项修改未保存 · 离开页面前请保存 · 放弃 · 保存」。
2. **未保存保护**：有修改时切换页面会确认；关闭或刷新浏览器标签页由浏览器提示。
3. **已修改标记**：被改动的行/字段左侧出现黄色细线与「● 已修改」；侧边锚点导航中对应分节显示黄点。
4. **覆盖与恢复**：运行参数中由后台覆盖 config.yaml 的项显示「● 后台已覆盖 · 恢复默认」；字段下方显示范围与 config.yaml 中的值。
5. **表格**：工具条 = 搜索（防抖）+ 下拉筛选（虚线框，选中后显示「状态：失败 ×」）+ 右侧 刷新 / 密度 / 列设置（勾选显示的列，按表记忆）；筛选写入地址栏，可分享、可后退。
6. **详情**：点表格行在右侧打开详情抽屉，地址栏带 `?task=` / `?user=`，可直达；抽屉内的任务链接可继续打开任务详情。
7. **反馈**：所有操作结果用右上角吐司；危险操作（删除、停用、取消管理员）需确认，自我保护规则由后端保证并以吐司提示。

## 4. 页面

### 4.1 概览 `/admin/overview`
- 页头右侧：分段「7 天 / 14 天 / 30 天」+ 刷新。
- **KPI 行**（6 张等宽卡片，宽屏一行，窄屏 3/2 列）：近 N 天任务（完成率 · 进行中数，附每日迷你柱，失败日加深）、模型调用（成功率 · 失败次数）、Token（输入 · 输出）、费用（待核算次数）、已读网页（生成文件数）、用户（对话数）。可跳转的卡片悬停出现 →。
- **图表行**：每日任务堆叠柱（完成绿 / 失败橙 / 其他浅蓝，占 2/3）；各智能体调用次数横向条（悬停看 token 与平均耗时）。
- **列表行**：按模型（表格）；搜索引擎状态（启用/未启用/冷却中，链接到「检测」「配置」）；最近失败（任务 → 打开任务详情抽屉；调用 → 跳到调用记录并筛选失败）。

### 4.2 模型与供应方 `/admin/models`（主从布局）
- 左栏 280：供应方列表（字母头像、名称、模型数 · 类型、状态点：绿=启用、黄=未设置 Key、灰=停用），选中项记在地址栏 `?p=`。
- 右栏：所选供应方的头部（名称、类型、启用开关、编辑、删除）与连接信息（接口地址、Key 掩码、模型数）；下方该供应方的模型表：模型（显示名 + 模型 ID）、能力标签（工具 / 非强制 / Schema / JSON / 图片）、上下文、单价（入/出，未知标黄）、使用中（被几个智能体使用，悬停看是哪些）、启用、操作（上次测试结果图标、测试、编辑、删除）。
- 页头操作：「添加供应方」「添加模型」（添加到当前供应方）。表单与测试结果都在右侧抽屉。
- 空状态：引导添加第一个供应方。

### 4.3 智能体分工 `/admin/agents`
- 顶部一行说明（含当前默认模型）；右上「管理模型（N 个可用）」。
- 表格每个角色一行（默认模型 + 8 个智能体）：智能体（中文名 + 建议标签「强推理 / 快速低价 / 长上下文」+ 英文键，第二行职责说明单行省略）、主模型（按供应方分组的下拉；非默认角色可选「使用默认模型」）、备用模型（按顺序多选）、温度、最大输出、状态（已修改 / 用默认）。
- 统一保存条；「使用默认模型」保存时删除该角色的单独绑定。

### 4.4 运行参数 `/admin/settings`
- 左侧吸顶锚点导航：搜索引擎、垂直来源、冷却策略、浏览器与人工接手、任务限额、部署配置（只读）。`/admin/search`、`/admin/limits` 跳转到对应锚点。
- 每节一个面板：标题 + 一句说明；字段为“左标签/右控件”的行：左侧 标签、说明、范围、config.yaml 中的值、覆盖状态与「恢复默认」；右侧 控件（引擎顺序列表：拖动、上下移、开关；分段；多选标签；数字步进；开关）。
- 部署配置：服务 / 数据库（密码打码）/ 云端浏览器 的只读键值，注明 config.yaml 路径与“重启后生效”。
- 右上「检测引擎可用性」进入引擎检测。

### 4.5 引擎检测 `/admin/diagnose`
- 查询词输入 +「开始检测」（检测中变为「停止」，在当前引擎完成后停止）；显示将检测的通用引擎与垂直来源数量、浏览器与代理。
- 结果统计：可用 / 需人机验证 / 无法访问 / 结果无关 / 无结果 / 出错。
- 结果表逐行出现：引擎/来源、类型、结果胶囊、条数、耗时、说明（示例标题或错误）。
- 「怎么处理」：按出现的结果给出建议（设置 browser.proxy、调整顺序、换查询词等）。

### 4.6 任务 `/admin/tasks`
- 工具条：搜索（标题 / 任务 ID / 用户名）、状态（进行中 / 执行结束 / 失败 / 已停止 / 草稿）、模式。
- 表格：任务（标题 + ID）、状态、模式、发起人、模型调用、费用（未核算显示 +?）、创建时间、最近更新。
- **任务详情抽屉**（760）：头部状态、模式、标题、发起人、时间、ID、「打开对话」；标签页：
  - 概况：失败原因（如有）、模型调用 / Token / 费用 / 来源 四个小数字、需求原文与子问题、上限标签、执行轮次表（轮次、状态、开始、耗时、Worker）。
  - 步骤：序号、状态、步骤名（规划搜索 / 搜索 / 读取网页 / 抽取证据 / 覆盖评估 / 核验 / 撰写…）+ 智能体 + 节点 ID、重试次数、耗时；失败步骤可展开查看错误（等宽代码块）。
  - 来源：按读取状态计数；列表含序号、标题（新窗口打开）、站点、可信度、失败原因、状态。
  - 成果：文件名、类型、大小、记录数、生成时间。

### 4.7 调用记录 `/admin/runs`
- 工具条：搜索（模型 / 供应方 / 任务 ID）、智能体、状态（成功 / 失败）。
- 表格：时间、智能体、模型（供应方 · 请求次数）、状态（失败带错误图标）、耗时、Token 入/出、费用（待核算）、任务 ID（点开任务详情）。
- **调用详情抽屉**：错误信息（完整，代码块）、智能体、模型、请求次数、Token、费用、耗时、起止时间、所属任务（可打开任务详情）。

### 4.8 用户 `/admin/users`
- 工具条：搜索（用户名 / 昵称）。表格：用户（头像、昵称、@用户名、你）、角色（管理员胶囊 / 成员）、状态、对话、任务、注册时间。说明：排序只作用于当前页；不能取消自己的管理员身份；至少保留一个管理员。
- **用户详情抽屉**：头部头像、昵称、@用户名、角色与状态；对话 / 任务 / 模型调用 / Token；注册时间、用户 ID；最近任务（点开任务详情）；底部操作「设为/取消管理员」「停用/启用账号」（均需确认；对自己禁用）。

## 5. 状态

- 加载：表格骨架行、顶部细进度条；面板内「加载中…」。
- 空：一句话 + 下一步（如「添加第一个供应方」「点开始检测」）。
- 错误：吐司；表单保存失败的行保留草稿，便于修正后再保存。
- 响应式：≥1440 全部双/三栏；1024–1439 列表与表单单栏，表格必要时横向滚动（关键列固定）；<1024 侧栏为抽屉，表单行改为上下排列；390 手机可用。
