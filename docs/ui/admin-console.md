# 管理端（管理后台）

## 布局

- **左侧深色侧栏**（248，圆角 24，距边 12，近黑 `#111214`）：顶部 Logo“云搜浏览器 / 管理后台”；分组导航（灰色小标题 + 线性图标 + 文字）：
  概览；**模型**：供应方、模型、智能体分工；**运行**：搜索与浏览器、任务限额；**数据**：任务、调用记录、用户。
  当前项：白底黑字胶囊 + 右侧绿色小圆点。底部：用户卡（头像、昵称、“管理员”、深浅色切换）、「返回应用」、「收起导航」。收起后宽 72 只显示图标。
- **内容区**：面包屑（管理后台 / 模型）、页面标题（图标 + 36/700）、一句说明；右侧页面操作（时间范围、刷新、保存全部、新增）。最大宽 1680。
- 所有列表使用 Semi 风格 `DataTable`；编辑使用右侧抽屉；有未保存修改时底部浮出黑色保存条“有 1 项修改尚未保存 · 放弃 · 保存修改”。

- 第一行：
  - **主卡（饱和橙 #E8693C，白字）**：“近 14 天任务 95 · 累计 412 个任务”，右上胶囊“2 个进行中”，中部每日迷你柱（深橙），底部三栏：完成 86% · 失败 8% · 其他 5%。
  - **模型调用卡（白）**：8,432 次请求；输入 token 4123 万、输出 392 万（彩色圆点）；右侧绿色环形“99% 成功率”；底部“费用 ¥187.34 · 12 次待核算（黄胶囊）· 63 次失败（红字）”，右上“调用记录 →”。
  - 4 个小统计卡（白，图标在粉彩圆角方块中）：用户 14、对话 186、成果文件 233、已读网页 4,821。
- 第二行：**每日任务**堆叠柱状图（完成=绿、失败=橙、其他=浅蓝），占 2/3；**各智能体调用次数**横向条形图（淡紫），悬停看 token 与平均耗时。
- 第三行：**按模型**表格（模型名 + 供应方小字、调用、Token 入/出）；**搜索引擎**列表（状态圆点、名称、“冷却中”黄胶囊、“未启用”灰字、“垂直”标签，右上“配置 →”）；**最近失败**（任务/调用标签胶囊 + 标题 + 原因 + 相对时间）。

## 2. 供应方 `/admin/providers`

表格：名称、类型（OpenAI / DeepSeek / Kimi / 火山方舟 / 通义千问 / 智谱 / OpenAI 兼容）、Base URL、API Key（`sk-****mnop` 打码）、模型数、启用开关、操作（编辑 / 删除）。右上「＋ 添加供应方」打开抽屉：预设卡片选择（各家 logo 字母块）、名称、Base URL（预填）、API Key（密码框，“已保存，留空不修改”）。

## 3. 模型 `/admin/models`

筛选：供应方下拉 + 搜索。表格：模型（显示名 + 模型名等宽小字）、供应方、能力标签（工具调用、强制工具选择、JSON Schema、JSON、视觉）、上下文、最大输出、单价（输入/输出 元/百万 token）、启用开关、操作（测试 / 编辑 / 删除）。
「测试」在抽屉里显示：连通性、结构化输出探测结果、耗时、自动适配说明（如“该模型不支持强制工具选择，已自动改用提示词输出”）。

## 4. 智能体分工 `/admin/agents`

- 顶部左：淡紫说明卡（灯泡图标）“八个智能体各司其职，可绑定不同模型：理解、协调与核验建议用强推理模型；搜索规划与信息抽取调用最频繁，可用快速低价模型；报告写作建议用长上下文模型。未绑定的角色使用‘默认模型’，主模型失败时按顺序尝试备用模型。”；右：奶黄统计卡“3 个可用模型 · 管理模型”。
- 表格（每个角色一行，共 9 行：默认模型 + 8 个智能体）：
  - 智能体：中文名（粗体）+ 建议标签胶囊（建议强推理 / 建议快速低价 / 建议长上下文）、英文键（等宽灰）、职责说明。
  - 主模型：下拉（“供应方 · 模型名”，非默认角色可选“使用默认模型”）。
  - 备用模型：多选下拉，显示“1. DeepSeek V3.2”；空为“不使用”。
  - 温度、最大输出：小输入框，占位“默认”。
  - 状态与操作：“● 未保存”黄胶囊 / “● 用默认”灰胶囊 + 「保存」。
- 右上：“1 项未保存”+ 黑色「保存全部」。

## 5. 搜索与浏览器 `/admin/search`

两列：
- 左列 **搜索** 卡：
  - 通用搜索引擎顺序：可拖动列表（拖动柄、序号黑圆、名称、英文键、上下箭头、开关），未启用项灰显；标题旁“已修改（覆盖 config.yaml）”蓝胶囊 +「恢复默认」。
  - 使用策略：分段“优先 / 轮换”+ 说明。
  - 可用的垂直来源：黑色选中胶囊（Google、维基百科（中文）、Wikipedia (EN)、百度百科、微信公众号文章、GitHub、arXiv 论文）。
  - 数字项（步进器 − 10 +，右下“范围 3–20 · 默认 8”）：每次搜索取结果数、被拦截后冷却（秒）、无法访问后冷却（秒）。修改未保存的项加黄色描边 +“未保存”标签。
- 左列 **浏览器与人工接手** 卡：允许请用户接手（开关）、等待接手超时（秒）。说明“系统不会尝试绕过验证”。
- 右列 **引擎检测** 卡（mint）：查询输入框 + 黑色「▶ 开始检测」；“将检测 10 个：…；浏览器：系统 Edge；代理：未设置（直连）”。下方结果表：引擎/来源、结果（可用 绿 / 需人机验证 紫 / 无法访问 橙红 / 结果无关 黄 / 无结果 灰）、条数、耗时、说明（示例标题或错误）。表下“可用 6/10。‘无法访问’通常需要在 config.yaml 设置 browser.proxy”。
- 右列 **部署配置（只读）** 卡：“以下项在 config.yaml 中修改，重启后生效：D:\cloud_search\config.yaml”；分组小块：服务（监听地址、工作进程）、数据库（连接，密码打码）、云端浏览器（内核、无头模式、代理）。
- 底部浮动保存条。

## 6. 任务限额 `/admin/limits`

天蓝说明条：“这些是单个任务的默认上限，对之后新开始的任务生效…”。三列卡片网格，每个参数一张白卡：标题、说明、右侧步进器、右下范围与默认值；已修改的显示“已修改（覆盖 config.yaml）”+「恢复默认」。参数：每个任务最多读取网页（1–40）、最多搜索次数（1–20）、同时打开网页数（1–8）、最多模型调用（10–400）、研究任务补查轮数（0–4）。

## 7. 任务 `/admin/tasks`

筛选条：搜索（标题/ID/用户）、状态胶囊（全部 / 进行中 / 已完成 / 失败 / 已停止）、模式胶囊（快速搜索 / 深入研究 / 数据采集 / 数据+报告）。
表格：任务（标题 + ID 小字）、模式标签、状态胶囊（带 emoji 圆点）、当前阶段、用户（头像字母 + 昵称）、模型调用、费用、创建时间、更新时间；行点击打开对应对话。

## 8. 调用记录 `/admin/runs`

筛选：角色胶囊（9 个）、状态（全部 / 成功 / 失败）、搜索（任务 ID / 模型）。
表格：时间、智能体（中文名 + 键）、模型（供应方 · 模型）、请求数、Token 入/出、耗时（ms / s）、费用（¥ 或“待核算”）、状态（成功绿 / 失败橙，悬停显示错误）、任务 ID（可复制）。

## 9. 用户 `/admin/users`

搜索框。表格：用户（头像字母 + 昵称 + 用户名）、角色（管理员胶囊）、状态（正常 / 已停用）、对话数、任务数、注册时间、操作（设为管理员 / 取消管理员、停用 / 启用，均需确认）。
规则提示：不能取消自己的管理员身份；至少保留一个管理员。

## 10. 通用状态

- 加载：表格骨架行；卡片骨架块。
- 空：线条插画 +“暂无调用”“这段时间没有失败 🌿”。
- 错误：吐司 + 卡片内重试。
- 移动端（390）：侧栏变抽屉，顶部条显示页面名与菜单按钮；统计卡两列；表格横向滚动、首列固定。
